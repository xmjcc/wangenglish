# Jerry English

North American pronunciation course with 14 lessons, clickable word and sentence audio, schematic front/side mouth animation, slow replay, dictation, and device-local progress.

Website: https://xmjcc.github.io/jerry-english-course/

This public repository contains only the generated learning website and its required recordings. Account services, administration, credentials, databases, and the private project's history are not included.

Jerry recordings are original course audio. AI recordings are labeled non-Jerry. Mouth animations are schematic, not real-person videos. No voice cloning is used.

GitHub Pages serves the `docs` directory on the `main` branch. All lessons are open without registration. Learning progress stays in your browser.
